1. Executive Summary

The Pixous HR Portal is a comprehensive Human Resource Management System serving IT and Civil/Infrastructure industries. The system provides end-to-end management of employee lifecycle including attendance tracking, leave management, payroll processing, task management, chat communication, and reporting.

The application is accessible through three platforms: Web Application (React + TypeScript), Android Mobile App (Flutter/Dart), and Backend API (Spring Boot + Java 17). All platforms share the same backend, database, and real-time services.

4. Authentication Workflow

Login Flow

1
User enters username and password on Login screen
2
Frontend sends POST /api/auth/login with credentials
3
Backend validates credentials against MySQL database via Spring Security
4
Backend generates JWT Access Token + Refresh Token
5
Tokens stored in Secure Storage (Keychain/Keystore on mobile, sessionStorage on web)
6
GET /api/auth/me called to fetch user profile + roles + permissions
7
GET /api/my-modules called to determine which modules are enabled
8
Role-based routing: Employee → Dashboard, Admin → Executive Dashboard, Tech Admin → Tech Console
9
WebSocket connection established for real-time features

5. Employee Role Workflow

5.1 Daily Attendance

1
Employee opens Attendance tab
2
Taps "Punch In" → GPS coordinates captured → POST /api/attendance/punch-in
3
Alternative: "Punch In with Face" → Camera selfie → Face verification via Python analytics service
4
Server records punch with timestamp, GPS, geofence check
5
End of day: taps "Punch Out" → POST /api/attendance/punch-out
6
Dashboard shows worked hours, status, monthly history

5.2 Leave Management

1
Employee opens Leave tab → views leave balances (all types)
2
Taps "Apply" → selects leave type, dates, reason, approver
3
POST /api/leave/apply → notification sent to approver in real-time
4
Employee monitors status: Pending → Approved/Rejected
5
Can withdraw pending request via POST /api/leave/{id}/cancel

5.3 Chat & Communication

1
Employee opens Chat from More menu
2
Views channels: groups, direct messages, team chat
3
Messages sent via POST /api/communities/{id}/messages
4
Real-time delivery via STOMP WebSocket: /topic/community/{channelId}
5
Features: reactions, polls, voice notes, file attachments, pinning, replies
6
1:1 calls: voice call (WebRTC) and video call (WebRTC)

5.4 Other Employee Features

  • Tasks: View assigned tasks, update progress, mark complete
  • Work Reports: Log daily work (project, hours, description)
  • Claims: Submit travel/expense claims with receipts
  • Support Tickets: Raise IT/facility tickets with attachments
  • Complaints: Raise HR complaints confidentially
  • Payslips: View monthly payslip details
  • Profile: View/edit personal info, dark/light theme
  • Calendar: View holidays, birthdays, meetings
  • Safety: Report safety incidents (anonymous option)
  • AI Assistant: Ask about policies, leave, payroll

6. Team Lead Role Workflow

Additional TL Capabilities (beyond Employee)

Team Attendance

1
TL opens Team Attendance from More menu
2
Selects a date → GET /api/attendance/team?date=YYYY-MM-DD
3
Views all team members: present, absent, late, on leave
4
Clicks individual to see punch details, location, work hours

Leave Approval

1
TL opens Approvals from More menu
2
GET /api/leave/pending → shows pending requests from team
3
Approve: POST /api/leave/{id}/decision { decision: "APPROVED" }
4
Reject: POST /api/leave/{id}/decision { decision: "REJECTED", comment: "reason" }
5
Employee notified in real-time via WebSocket

Work Report Review

1
GET /api/work-reports/team → views team's filed reports
2
Can export to Excel, filter by date range

Task Assignment

1
Dashboard → Assign Task card → select team member or team group
2
POST /api/tasks → task created with title, description, due date
3
Assigned employee receives real-time notification

12. Data Flow Diagrams

Employee Attendance Flow

StepActorActionSystem
1EmployeeTap "Punch In"Mobile/Web captures GPS
2Mobile AppPOST /api/attendance/punch-in {latitude, longitude, mode: "MOBILE"}Backend validates geofence
3BackendCreate AttendanceRecord, calculate geofence statusMySQL INSERT
4BackendPush notification via Kafka → WebSocketTL/HR notified
5EmployeeTap "Punch Out"Mobile captures GPS
6BackendUpdate record with punch-out time, calculate worked hoursMySQL UPDATE

Leave Request Flow

StepActorActionSystem
1EmployeeOpen Leave → tap "Apply" → fill formGET /leave/types, /leave/balances, /leave/approvers
2EmployeeSubmit leave requestPOST /api/leave/apply
3BackendCreate LeaveRequest (status: PENDING)MySQL INSERT + Kafka event
4BackendReal-time notification to approverWebSocket push
5ApproverApprove/Reject with optional commentPOST /api/leave/{id}/decision
6BackendUpdate status, adjust balancesMySQL UPDATE + Kafka event
7BackendNotify employee of decisionWebSocket push + email
