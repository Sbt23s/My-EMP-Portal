1. Security Architecture Overview

Authentication & Authorization

LayerTechnologyDescription
AuthenticationJWT (jjwt 0.12.6)Access token + Refresh token pair. Tokens signed with HMAC-SHA256.
Token Storage (Mobile)flutter_secure_storageTokens stored in Android Keystore — hardware-backed encryption.
Token Storage (Web)sessionStorageCleared on tab close. Not accessible by JavaScript from other origins.
API AuthorizationSpring Security + CustomEvery endpoint checks JWT validity. Role-based access enforced by @PreAuthorize annotations.
Password HashingBCrypt (Spring Security)Passwords hashed with BCrypt. Never stored in plain text.
HTTPSTLS 1.3All production traffic encrypted. No cleartext HTTP allowed.
Real-TimeWSS (WebSocket Secure)STOMP connection over TLS. JWT token passed in connect headers.

2. OWASP Top 10 Assessment

#VulnerabilityRiskCurrent StatusDetails
A01Broken Access ControlMITIGATEDPass Role-based access enforced server-side. Employees cannot access admin endpoints. TL cannot access HR-only endpoints. API returns 403 for unauthorized access. Mobile app hides UI elements AND server enforces permissions.
A02Cryptographic FailuresMITIGATEDPass HTTPS enforced in production. No cleartext HTTP. JWT tokens signed with strong secrets. Passwords hashed with BCrypt. No sensitive data in URLs.
A03InjectionMITIGATEDPass JPA/Hibernate parameterized queries — no raw SQL. Input validation via Spring Validation (@Valid). Mobile app uses Dio for HTTP — no string concatenation in queries.
A04Insecure DesignMITIGATEDPass Multi-tenant architecture with company isolation. File uploads validated (type, size). Face verification uses server-side comparison. Geofence validation server-side.
A05Security MisconfigurationMITIGATEDPass Debug mode disabled in production. Error stack traces not exposed to clients. CORS configured. Security headers set. Flyway manages schema changes safely.
A06Vulnerable ComponentsLOW RISKReview Some dependencies have newer versions available (non-critical). Spring Boot 3.5 is current. Recommend periodic dependency audit.
A07Auth FailuresMITIGATEDPass JWT refresh token rotation. Concurrent refresh deduplication. Session expiry with automatic logout. Rate limiting recommended for production.
A08Data Integrity FailuresMITIGATEDPass File uploads validated server-side. WebSocket messages validated. Kafka message integrity maintained. Flyway checksums verify migrations.
A09Logging & MonitoringMITIGATEDPass Comprehensive audit logging (who/what/when/where). Login attempts logged. Failed auth logged. Spring Actuator health endpoint.
A10SSRFMITIGATEDPass No user-supplied URLs processed server-side. File uploads stored locally. WebSocket connections use server-controlled endpoints.
