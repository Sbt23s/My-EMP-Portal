1. Project Overview

1.1 Purpose

The Pixous HR Portal is a multi-tenant Human Resource Management System designed for IT and Civil/Infrastructure companies. It provides end-to-end management of employee lifecycle including attendance, leave, payroll, tasks, communication, and reporting.

1.2 Scope

ComponentTechnologyPurpose
Web ApplicationReact 19, Vite, TypeScript, TailwindCSSPrimary interface for all roles including System Admin
Mobile ApplicationFlutter 3.44, DartEmployee/TL/HR mobile interface
Backend APISpring Boot 3.5, Java 17REST API + WebSocket server
DatabaseMySQL 8.0 + FlywayPersistent storage with schema migrations
Analytics ServicePython microserviceFace verification, AI insights
