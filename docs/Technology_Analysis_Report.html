Face Verification Pipeline

Upload selfie → face_recognition.load_image → face_locations → face_encodings → compare with enrolled (tolerance 0.5) → liveness check (dual-frame motion ≥0.8) → landmark analysis (blink/smile/head turn) → frame quality assessment → confidence score → match/fail
